# 骑完之后，哪个问题值得问

一次骑行刷新了近期五分钟功率纪录。系统不确定这是比赛、团骑中的追赶，还是独自测试，于是准备问：“这是比赛吗？”

在发送之前，还缺一个判断：知道答案之后，系统究竟能更可靠地做什么？如果真正困惑的是那五分钟是否持续全力、功率计是否异常，赛事身份未必能回答这个问题。即使用户明确说“是比赛”，也不能据此确认每一段输出都适合作为能力观测。

Q784原答强调只在有信息价值时提问，方向值得研究；但它同时把破峰、NP超计划15%、分类不能达到100%确定，以及未来课表改变联系成一套触发条件。这些数值和逻辑还没有本场景验证。要评价它们，先要把“知道更多”和“做得更好”分别定义。[原题与原答](#/article/series-guide?section=publication)

## 主动学习可以选择标签，询问也可以服务眼前的决定

主动学习通常让模型选择哪些未标注样本值得交给标注者，以较少的标签改进学习。不确定性抽样是其中一种方法：优先选择模型难以判断的样本。但回答者可能出错，不同问题的标注成本也不同；少问几题不自动等于少花同样比例的时间。[Settles，2010更新版，§3.1、§6.2—6.3](https://burrsettles.com/pub/settles.activelearning.pdf)

骑行后的问题可能承担三个不同任务：完善活动分类器、澄清当前状态，或改善某个训练决定。三者可以关联，却不能只用“信息增益高”一并代替。为了未来模型训练而收集标签，与为了眼前一次选择而求证，还可能需要不同的评价和授权。

一个问题的价值，应相对于具体目标来理解。假如只关心明天某个决定，那么某些容易确认的背景信息即使让活动记录更完整，也可能不改变该决定。反过来，一条不显眼的常规记录，也可能正好补上关键缺口。峰值是候选线索，不是信息价值的定义。

## 最多的信息，未必带来最多的决策改善

用一个有限例子拆开这两件事。假设系统关心二元状态θ，它取1的概率为20%；另有一个与θ独立的背景事实u，两个取值各占一半。系统必须在动作0和1之间选择，选错损失为1，选对为0。这里的状态与损失是演示设定，并不对应某种真实训练处方。

不提问时，系统选动作0，平均错误风险为0.2。现在考虑三种问题。

|问题|对完整状态取得的信息|提问后的平均最小错误风险|当前决策改善|
|---|---|---|---|
|准确获知背景u|1bit|0.2|0|
|询问θ，回答有80%正确率|约0.182bit|0.2|0|
|准确获知θ|约0.722bit|0|0.2|

第一题解决了一个原本完全未知的背景事实，因此信息量最大。但它与目标状态独立，动作选择没有获得帮助。第三题的信息量较小，却直接消除了决定所依赖的不确定性。

这不是在说“比赛身份没有价值”。它只说明必须先写清：信息关于什么，行动依赖什么。如果赛事身份确实与目标状态有关，就应通过相应关系评价，不能把本例的独立假设套到真实活动上。[完整联合分布与结果](#/article/series-guide?section=publication)

第二题更微妙。用户回答“是”的概率为0.32，收到这个答案后，θ为1的概率恰好变成0.5，两种动作损失相同；回答“否”的概率为0.68，后验概率约为0.0588，仍选择动作0。把两个分支加权，最小风险仍是0.2。因此，这条回答确实改变了信念，也带来了信息，却没有降低本例当前动作的期望损失。

如果还考虑之后的问题、不同错误成本或长远模型学习，这条信息可能有其他价值。本例只检验已经声明的当前二行动目标，不能据此规定“眼前动作不变就永远不能问”。

## 有信息的回答，有时反而让人更不确定

在上述第二题中，提问前θ为1的概率为0.2，系统较倾向于0；收到“是”后，它变成0.5，反而更难区分。目标熵从约0.722bit升到1bit。

这不违背信息在期望上减少不确定性的结论。另一个“否”分支把概率降到约0.0588，变得更确定；将两种答案按概率加权，后验目标熵约0.539bit，仍低于提问前。一个是平均结果，一个是实际发生的单个分支。

这一区别会影响如何解释界面上的区间或置信度。用户补充背景后，模型发现原先判断可能过于确定，扩大不确定性可能是合理更新。不能预先承诺每次确认都会让区间变窄，也不能把“模型变化很大”直接当作模型变好；错误标签同样可能推动很大的变化。

## 一条问题的价值要把“不回复”和“答错”算进去

继续用单位误判损失，但把两种状态的先验改为各50%。设用户回复的概率为r，回复后的正确率为q。两者不同：一个衡量能否获得答案，一个衡量获得的答案有多可靠。

在这个简化设定里，不回复与状态独立，对称回答正确率固定。相对于不问，提问带来的平均风险减少为r(q−0.5)。假设每次尝试还带来0.05单位成本，会得到以下结果。

|回答正确率q|回复概率r|未扣成本的改善|净改善|
|---|---|---|---|
|90%|80%|0.32|0.27|
|90%|20%|0.08|0.03|
|60%|80%|0.08|0.03|
|60%|20%|0.02|−0.03|

最后一种情况仍能得到一点信息，但在设定成本下不值得问。成本0.05不是15秒，也不是某种训练风险的实测值；只有先把后果和负担放进一致的评价口径，才可以比较。真实回复往往不独立于情境，这个公式不能直接用作产品规则。

更一般地，可以比较：现有证据下能达到的最小预期损失，与对所有可能回答——包括无回应——分别更新后，再作最优选择的平均损失。两者之差是本目标下未扣成本的信息价值，再扣提问成本，才得到净值。这个比较依赖可信的回答模型和损失定义，并不会因为写成公式就变得已知。

## “这是比赛吗”应当能追溯到一个具体缺口

如果缺的是赛事背景，直接询问身份可能合适；如果缺的是某段是否全力，询问努力意图更贴近目标；如果怀疑数据异常，就需要检查设备与记录。问题越短越好并不是唯一标准，选项还要容纳用户的真实情况，包括不知道或不适用。

标签本身的依据与用途，已在[Q783文章](#/article/p1-043-01-who-can-label-a-ride)中展开。当前研究没有证明哪种问法对骑手最有效，也没有批准按某个概率自动弹窗。它保留的是一个判断顺序：先明确未知事实和用途，再检查回答是否能改变相关证据，最后把质量、无回应、负担和后续机会纳入比较。
