# 恢复度权重开始学习前，先说明它要学会什么

早晨打开训练应用，系统给出0.72的恢复度。晚上训练完成了，账本里又多了一条成功记录。直觉上，系统似乎应该用这个结果调整恢复度的四个权重，让下一次更准。

但更准需要一个明确对象。0.72是在描述当天的主观感受，表示某项任务完成的概率，还是决定今天应选哪种训练？这三种用途可能相关，却不共享一个不需说明的正确答案。账本可以积累证据，不能替系统定义目标。

[Q511](#/article/series-guide?section=publication)问的正是四权重能否校正及校正什么。本篇先核对实际公式，再解释学习目标与参数识别；下一篇讨论评分与行动反馈。

## 1. 原式的四个数字不是四种生理贡献

[实际提案§3.5](#/article/series-guide?section=publication)把恢复度定义为决策层的软惩罚输入。简化记号后是：

$$R=\operatorname{clip}(1-0.35h-0.25s-0.2d-0.2z,0,1).$$

h为HRV异常指示，s为归一化到0—1的主观疲劳，d为心率与功率解耦异常指示，z为症状指示。这里的clip表示把结果限制在0—1。原答另列睡眠、HRV z分数、体感和近期负荷，还混入另一个TAI指数；这会改变变量含义，不能作为同一公式的解释。

四项都是不利信号：其余相同时，某项增加使R下降。0.35意味着在这一规则里，HRV指示从0变1将扣去0.35；它没有因此被验证为HRV贡献了35%的恢复能力。系数还依赖输入尺度、其他特征及目标，不能直接解释为生理或因果占比。

原答提出用σ(wᵀx)拟合成功结果，其中σ是把实数压到0—1的sigmoid函数。若直接沿用上述0—1不利输入、非负且和为1的权重，又没有截距，那么wᵀx只能落在0—1，输出只能在0.5到约0.7311。无不利信号时输出0.5，全部最不利时反而输出约0.7311。

这既不能表达更低或更高的成功概率，方向也与原式想表达的惩罚相反。问题来自这个具体表达，不是sigmoid普遍不能使用。重新定义变量方向、连接和截距，可以形成别的候选模型，但必须交代清楚；不能把一个0—1得分直接改称概率。本批枚举了40种输入，保存了[原分数与连接输出](#/article/series-guide?section=publication)。

## 2. 描述感受、预测结果与选择行动，需要分别定义

如果研究对象是本人感到多疲劳，主观回答可以是明确的测量对象。此时要关心问法、时间范围、重复测量和构念效度。若研究对象是明天某个指定任务能否完成，目标就变成该任务、该时间及相应条件下的结果。若要决定今天选哪种训练，还需要比较行动后果与本人目标。

因此，主观结果绝不能作为目标的说法过强。Saw等的系统综述纳入56项同时报告主客观指标的研究，支持主观指标用于监测研究范围内的状态变化。它没有验证本提案四权重，也不能把一个主观分数当作全部生理恢复的真值；测量时间和实施方式仍会影响解释。[Saw等，2016](https://pubmed.ncbi.nlm.nih.gov/26423706/)

同样，把原来的R当标签，再训练一个模型去还原R，只能检查能否复制旧规则。它没有提供独立证据证明R有助于预测或决策。如果某项主观回答既作为输入又直接决定标签，得到很小的拟合误差也可能只是复述输入。

本批用一个构造说明目标如何改变权重。给同样四项输入设两个目标均值，分别由A=(0.6,0.1,0.2,0.1)和B=(0.1,0.6,0.1,0.2)生成。在零输入、四个单项输入和全1输入这六个点上，拟合目标A时，A误差为0、B均方差约0.0867；拟合目标B时，结论反过来。

这里的目标名称只是主观严重程度与任务失败的演示标签，数值没有实测含义。例子证明的是，数据支持哪组权重与目标有关。不能先声称四个数字有唯一正确值，再事后寻找一个指标让它们看起来合理。[六点对照与误差](#/article/series-guide?section=publication)

## 3. 稳定选出一个解，不等于四项都被识别

即使目标已经定义，数据也未必能够分别告诉我们四个权重。假设第一项与第二项总是同时变化，第三项与第四项也总是一起变化。输入只出现(h,h,d,d)这四种组合：全0、后一对为1、前一对为1、全1。

此时以下三组权重给出完全一样的预测：

|候选|四个权重|前一对之和|后一对之和|
|---|---|---:|---:|
|w0|0.35、0.25、0.20、0.20|0.60|0.40|
|w1|0.10、0.50、0.35、0.05|0.60|0.40|
|w2|0.30、0.30、0.20、0.20|0.60|0.40|

数据只能区分两对的总作用，不能区分每对内部如何分配。重复再多相同输入，也不会让原来一起变化的两个特征突然分开。

正则化可以偏向某组权重。假设我们给距离初始权重越远的候选越大惩罚，三个候选的预测误差都一样，那么以w0为中心就选w0，以w1为中心就选w1，以w2为中心就选w2。选择明确了，信息缺口却还在。这里比较的是三个离散候选，未声称求得一般连续优化的最优解。

当一个从未出现过的新输入(1,0,0,0)到来时，三者预测分别为0.35、0.10和0.30。历史支持内等价，并不保证新组合下等价。[全部正则距离与预测](#/article/series-guide?section=publication)

正则化仍可能有实际价值，例如控制估计波动。但它提供了偏好或约束，不能被写成数据已经识别了某个系数。真实特征也不一定完全共线；需要用实际变化、噪声和模型检查来判断识别程度。

## 4. 时间常数与权重能否一起估计，取决于观测结构

原答要求时间常数与权重不能同时自由更新，并把相同学习率与不可识别联系起来。这把两类问题合并了：学习率决定计算如何移动，可识别性决定不同参数能否产生可区分的观察。

用一个抽象模型说明：y=exp(−t/τ)+wx，初始幅度固定为1。第一条观察在t=1、x=1，结果为0.90653。以下三组参数都能匹配它：τ=1且w约0.53865；τ=2且w=0.3；τ=4且w约0.12773。只有这一条观察时，两种作用没有分开。

再增加一条t=2、x=0的无噪声观察，结果为0.367879。因为x=0，这条观察只剩exp(−2/τ)，可以反解τ=2，再从第一条得到w=0.3。第二条提供了新的区分信息；换一种优化顺序本身不会提供这样的信息。

这只反驳联合估计必然不可识别。真实模型可能有未知初始状态、相关输入、噪声和变化机制，不一定具备这个例子的条件。冻结某些参数可以简化计算，但冻结值若错误，也可能把误差转移到其他权重。[联合候选与残差](#/article/series-guide?section=publication)

因此，8—12周并不是从四个权重自动推导出的充分期限。数据要求涉及目标事件、候选参数和预期性能；对单个人反复记录，还要考虑时间依赖与有效变化。已有样本量方法强调情境条件，本批没有据此算出个人训练的具体周数。[Riley等，2020](https://www.bmj.com/content/368/bmj.m441)

可以保留的研究方向是：先说明目标与模型，再判断数据能区分哪些参数，最后检验新时间段的用途。权重学习不是把四个固定数字替换成四个自动数字。[下一篇](#/article/p1-048-02-what-the-ledger-can-validate)说明账本中的成功、失败和评分为何还不能直接回答行动是否更好；[总目录](#/article/series-guide?section=publication)保留全部材料。
