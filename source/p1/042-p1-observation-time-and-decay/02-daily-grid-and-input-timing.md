# 要修正时间错位，先弄清负荷何时进入模型

发现日步模型可能把训练时间压缩得过粗，很容易得出一个结论：放弃按天计算，改成连续时间戳更新。这个选择可能有用，但它没有自动解决最重要的问题——一场持续数小时的训练，究竟怎样进入模型？

日历日期、计算网格和负荷输入并不是同一回事。日网格可以保留精确贡献；按事件更新也可能仍把整场训练压缩成结束时刻的一笔输入。本轮用同一个指数模型比较这些差别。[预定构造及核验方法](#/article/series-guide?section=publication)

## 1. 每天一步，不必然产生数值截断

如果没有新输入，指数衰减满足：

\[
x(t+\Delta)=x(t)e^{-\Delta/\tau}.
\]

先走半天，再走半天，与一次走一天完全相同。这是所设方程的精确关系，不是用直线近似曲线的数值步骤。因此，看到每天乘一次指数，不能直接把它称作离散化截断误差。

真正需要检查的是新输入如何加入。假设一天内有两笔模型输入：第0.25天加入40，第0.75天加入60，τ为2天。到第1天时，前一笔已经衰减0.75天，后一笔只衰减0.25天。

若要在第1天的网格上合并它们，等效输入应为：

\[
U=40e^{-0.75/2}+60e^{-0.25/2}\approx80.44.
\]

它不是原始总量100，因为两笔输入此前已经经历不同长度的衰减。

## 2. 网格和逐事件计算，可以得到同一个结果

令最初状态为20，查询第1.5天。直接计算初始状态和两笔输入的剩余贡献，结果约72.095。先在第1天使用刚才的有效输入80.441，再传播半天，结果仍为72.095。

如果省略输入时刻，在第1天把100全部加入，结果变成87.327。差异来自把输入集中到了一个较晚的时刻，并非日网格这个名称本身。[三种计算及中间状态](#/article/series-guide?section=publication)

这种等价有条件：采用相同的线性指数关系，并保留正确的输入权重。权重还依赖τ。实际提案在多个τ候选上估计后验，就不能认为预先保存一份不随τ变化的有效日输入，能对所有候选都保持精确。

这里是在比较数学表示，没有选定新的数据模型或实现架构。日历展示可以保留原有活动归属，只要它不被误用成未经说明的物理输入时刻。

## 3. 把全部负荷放到结束时刻，也是一种假设

原答建议绑定活动结束和晨间评估的时间戳。对一个在结束时刻瞬间加入的脉冲，这样计算确实能精确使用两者之间的间隔。但训练发生在结束之前，不能因此声称已经精确描述了整场过程。

为看清差别，假设100单位输入均匀发生在两小时内，结束后六小时查询，τ仍为2天。按每一小段输入实际发生的时刻积分，状态约86.436。若把全部100放在结束时刻，则得到88.250，高约2.10%。

| 输入约定 | 查询状态 |
|---|---:|
| 两小时均匀发生 | 86.436 |
| 全部放在结束时刻 | 88.250 |
| 全部放在中点 | 86.430 |
| 全部放在开始时刻 | 84.648 |

中点在这个例子中非常接近，但仍不是严格相等。均匀输入也只是对照假设，不是本轮测得的真实训练刺激。需要从任务定义和数据决定适合哪种输入过程，而不是因为用了更精确的时钟，就认为其他假设已经成立。[输入分布对照](#/article/series-guide?section=publication)

## 4. 观测发生在活动内部时，结束时刻还不够

晨间状态发生在活动结束之后，相对容易说明查询时刻。但一个20分钟MMP可能发生在骑行前半段，其后还有几小时运动。

如果用整场结束后的负荷状态去解释之前的20分钟表现，就可能把后来发生的输入带入较早的观测。反过来，只用活动开始前状态，又可能遗漏窗口之前已经发生的运动。应当先确定观测对应哪个区间、模型输出对应什么时刻，以及窗口内输入如何进入观测关系。

这里不能替实际系统补一个默认答案。提案中的观测日期和每日递推还缺这层明确说明。保留时间戳是必要的信息基础，但并不自动解决状态与观测的对应方式。

## 5. 时间处理准确，不等于测到了真实疲劳

实际提案的τ3=2天是参数网格的先验中心之一，并不是这位骑手中枢疲劳或能量恢复的直接测量。把指数通道命名为神经肌肉疲劳，不能单凭命名建立生理效度。

Busso等的原始研究比较过从同一训练—表现模型构造不同体能与疲劳指标的方法。它提醒我们，模型拟合表现与潜在分量的解释仍需区分；这项单名链球运动员研究并不能验证自行车的2天常数。[原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/7957156/)

也不宜把所有名为Form的值与这里的三通道表现方程视作同一对象。TrainingPeaks官方帮助把今日Form定义为昨日CTL减昨日ATL；官方方法说明将42和7天称为默认时间常数，并区分负荷指标与带增益的表现模型。这些口径需要分别核对，不能只按名称互换。[Form定义](https://help.trainingpeaks.com/hc/en-us/articles/204071764-Form-TSB)、[方法说明](https://www.trainingpeaks.com/learn/articles/the-science-of-the-performance-manager/)

本题下一步需要补的是实际计算语义：输入何时生效、状态代表何时、观测对应何时、输出用于什么判断。弄清这些，才能确定误差来自哪里，以及是否值得改变实现。当前的限定计算已经完成；真实系统偏差、个体恢复和训练效用仍未验证。[研究边界](#/article/series-guide?section=publication)
