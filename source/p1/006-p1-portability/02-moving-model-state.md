# 迁移模型状态时，究竟迁移了什么？

这篇文章继续回答Q185中的一个具体难点：如果用户能带走历史和个体参数，是否就带走了系统对自己的理解？

参数不是脱离语境的事实。一个数值必须与它估计的对象、单位、适用时间、模型和所用证据一起解释。下面用两个小模型说明。它们是本轮构造的解析例子，没有使用真实运动员数据，也不证明某个训练模型正确。

## 1. 先从最容易忽略的单位开始

设一个抽象评分随时间的模型为：

\[
y=a+b\,t_{\mathrm{日}}.
\]

其中，\(a\)是时间零点的评分，\(b\)是每天的变化量。我们对两个参数的均值估计分别为100和2，所以14日时的均值预测为：

\[
100+2\times14=128.
\]

现在接收方以周计时。因为\(t_{\mathrm{日}}=7t_{\mathrm{周}}\)，同一个模型应写成：

\[
y=a+(7b)t_{\mathrm{周}}.
\]

两周时，均值仍是\(100+14\times2=128\)。若直接复制参数数值，接收方会算成\(100+2\times2=104\)。文件读取成功了，计算也没有报错，含义却已经改变。

这只是确定性部分。实际估计还有不确定性，不能只把每天的均值2换成每周14。

## 2. 为什么协方差也要迁移

假设参数协方差矩阵为：

\[
\Sigma=
\begin{pmatrix}
4&0.2\\
0.2&0.09
\end{pmatrix}.
\]

对角线4和0.09分别是\(a\)、\(b\)的方差。非对角线0.2说明两者的估计误差有关联。预测的不确定性来自这些误差共同作用，不能只看每个参数各自的范围。

若仅考虑参数不确定性，\(a+bt\)的方差为：

\[
\operatorname{Var}(a+bt)=\operatorname{Var}(a)
+2t\operatorname{Cov}(a,b)+t^2\operatorname{Var}(b).
\]

在14日时，它等于\(4+2\times14\times0.2+14^2\times0.09=27.24\)。这是方差，不是标准差；也没有包含未来观测自身的新增噪声。

从日改为周，相当于对参数向量做线性变换：

\[
\theta'=A\theta,\qquad
A=\begin{pmatrix}1&0\\0&7\end{pmatrix}.
\]

因此均值和协方差应一起变化：

\[
\mu'=A\mu,\qquad \Sigma'=A\Sigma A^{\mathsf T}
=\begin{pmatrix}4&1.4\\1.4&4.41\end{pmatrix}.
\]

为什么方差要乘49而不是7？因为随机变量放大7倍后，它偏离均值的距离放大7倍，平方偏差就放大49倍。协方差涉及两个变量各自的缩放，所以这里乘\(1\times7\)。

把新矩阵与两周的时间一起代入，方差仍为27.24。如果只改参数均值，保留旧矩阵，均值虽然正确，方差却变成5.16。结果看似预测一致，实际置信程度已经不同。

| 处理方式 | 两周时的均值 | 参数方差 |
|---|---:|---:|
| 原模型以14日计算 | 128 | 27.24 |
| 均值与协方差都转换 | 128 | 27.24 |
| 原样复制参数 | 104 | 5.16 |
| 只转换均值 | 128 | 5.16 |

这个例子说明，检验迁移只比较一个预测值是不够的。不过它使用的是已知、可逆的线性变换。换模型结构、改基线定义或改时间零点时，需要另行推导，不能照搬这张矩阵。

## 3. 后验已经包含哪些历史

再看一个与单位无关的问题。设某个未知量\(\theta\)的初始分布为\(N(0,1)\)。本文\(N(\mu,v)\)的第二个参数表示方差。获得一次观测\(y=1\)，并假设：

\[
y\mid\theta\sim N(\theta,1).
\]

在这组正态模型假设下，方差的倒数称为精度。先验和独立观测各提供一份精度，所以更新后的方差为：

\[
v_1=\frac{1}{1+1}=\frac12.
\]

均值是按精度加权的平均：\(\mu_1=(0+1)/(1+1)=1/2\)。因此第一次更新得到\(N(1/2,1/2)\)。

假设旧平台将这个后验交给接收方，同时交付原观测记录。接收方可以把后验作为后续推断的起点，但不能再假装旧观测是独立的新信息。如果这么做，精度会从2增加到3，得到：

\[
v_{\mathrm{重复}}=\frac13,\qquad
\mu_{\mathrm{重复}}=\frac{(1/2)/(1/2)+1}{2+1}=\frac23.
\]

结果更靠近观测值，方差也更小，却没有新的事实支持这种变化。问题出在把同一证据用了两次。

从概率关系看，第一次后验已经与\(p(\theta)L(y\mid\theta)\)成比例；重复更新会得到\(p(\theta)L(y\mid\theta)^2\)。似然多乘了一遍，并不会因为换了平台而合法。

## 4. 相同数值也可能是真正的新证据

如果迁移后实际进行了一次新的独立观测，结果恰好仍为1，那么第二次更新可以成立。计算数值与前面的错误复用相同，但证据关系不同。

这说明不能通过“值是不是一样”判断重复，也不能只看最后输出是否合理。需要知道这条记录来自哪一次观察、旧估计是否已经使用它，以及独立性假设是否成立。记录有不同编号也不自动证明独立；如果两条记录来自同一次测量的不同导出，编号不同仍可能包含同一信息。

在本例的固定正态模型内，旧后验可以概括历史对\(\theta\)的作用。若接收方更换观测噪声模型，或者需要重新判断历史是否受异常仪器影响，单独的后验可能不够。这时要回到原始观测和形成条件重新分析，而不是继续加减精度。

## 5. 从算例回到真实迁移

两个算例共同说明：保留估计，需要同时保留解释估计的条件。前一个例子涉及参数定义与不确定性；后一个涉及证据沿用与信息重复。把“先验”“后验”两个名称互换，不能改变这些关系。

但参数搬运并非迁移的唯一方向。当目标模型没有相同含义的参数时，也许只能保留观测、条件和历史解释，让新系统重新估计。这样可能得到不同结果。不同本身并不等于失败；还要看差异来自合理的新假设，还是遗漏、重复计数或语义错误。

反过来，即使两套系统的计算完全一致，也没有证明用户能理解差异、承担迁移成本或继续原任务。数学一致性支持的是一个明确模型内部的结论。用户自主性的现实问题，需要回到[主文](#/article/p1-006-01-personalization-and-autonomy)中的选择条件来判断。
