# 更完整的记录，能否直接成为主记录

一份记录覆盖整趟骑行，另一份缺了几个时段。完整记录通常提供更多观察，但完整度并不回答测量偏差，也不说明缺失对某个指标有多大影响。要比较两份记录，必须把数据是否存在、存在的值是否可信，以及准备计算什么分开。

## 1. 缺失的位置会改变结论

构造一段12秒任务，每个数值都明确代表一秒区间：前9秒100W，后3秒400W。真实均值175W，总机械功2100J，最高连续三秒平均功率400W。

记录A完整，但每个值都偏高10W。记录B在已有时点准确，却缺失最后3秒。我们比较三种处理：

|处理|原始观测覆盖|计算均值的时间分母|所得均值|所算机械功|
|---|---|---|---|---|
|A完整报告|100%|12秒|185W|2220J，完整报告积分|
|B仅用已有值|75%|9秒|100W|900J，仅已观测部分|
|B缺失处填零|仍为75%|12秒|75W|900J，零填充估计|

填零后每个位置都有数值，却没有增加真实观察。B在已有9秒内测得准确，也不表示它足以给出全段平均或三秒峰值。A覆盖完整但含偏差，不能因此称为绝对准确。[完整结果](#/article/series-guide?section=publication)

这里的真实末段只因为是构造例子才已知。实际文件缺失时，不能凭两份文件的外观就知道缺失值是多少。这个例子也说明一分钟阈值为什么不能通用：短暂缺口若恰好覆盖目标冲刺，对该指标的影响可能很大；更长缺口对另一个特定时段的指标则未必有影响。

选择依据应对应用途。研究全程机械功，需要全程覆盖和积分口径；研究某段持续输出，需要该段连续数据和可信时间。一个笼统完整度总分无法替代这些条件。

## 2. 整段平均相同，短时间结果仍可能不同

再构造两条12秒序列。两者都在100W基线上有一次400W、持续3秒的脉冲，只是B比A滞后一秒。每条序列的整段均值都是175W，机械功都是2100J，最高连续三秒平均都是400W。

如果按文件中的同名时点直接求平均，脉冲两端就各变成250W，中间两个时点仍为400W。最高连续三秒平均降到350W，尽管整段平均和机械功完全没变。

|序列|全段平均|机械功|最高连续三秒平均|
|---|---|---|---|
|原记录A|175W|2100J|400W|
|滞后一秒的B|175W|2100J|400W|
|未对齐就逐点平均|175W|2100J|350W|

因此，汇总值相同不能证明短时指标可以互换。这个一秒差异是人为设定，不是对真实手表和码表的误差估计。现实中还要区分固定时间偏移、时钟漂移、记录时点和信号处理延迟，不能统一假定都是1—3秒，也不能未经核对就指定插值方案。

## 3. 逐点挑较高值会制造新的时间结构

对上述两条错位序列，如果每秒都保留较高值，就会把A较早出现的高值与B较晚结束的高值连接起来。合成记录中的400W持续4秒，而两条原记录各自只有3秒。

合成后的整段均值变为200W，机械功2400J，比任一原记录多300J。最高三秒平均仍是400W，所以只检查峰值还发现不了累计量的变化。本批保留了全部窗口和每个时点的取值来源，便于回查这个过程。[完整序列与来源](#/article/series-guide?section=publication)

这不是说任何补齐或融合都不可能有效，而是说合成后的序列需要自己的依据。它不再是任一原设备直接记录的结果。选择整份文件、按区间补齐、逐点平均和逐点择高，是不同操作，不能统一称为去重。

## 4. 同一事件的计数与功率来源分别判断

既然已确认两份文件属于同一骑行，在描述实际训练事件时就不应把它们算成两次独立训练。但保留一份事件表示，并不要求无条件丢掉另一份原始证据；反过来，保存两份文件也不意味着要重复累计负荷。这里说明的是计数语义，尚未定义或实施任何平台存储规则。

实际裁决可以围绕四项明确问题展开：

1. 两份记录接收的是同一功率源，还是不同测量位置和尺度的功率源。
2. 对准备计算的指标，哪些时间段有连续、含义明确的观察。
3. 差异能否由暂停、采样、零值平均、时间偏移或已知设置解释。
4. 若仍无法确定，哪些结论只能限定范围，哪些指标应保留未知。

当前没有用户的原始双录文件和独立参照，因此本批不会指定某份真实主记录，也不会采用码表优先、3%切换或一分钟缺失规则。得到的是解释和核对顺序，真实选择效果仍待验证。
