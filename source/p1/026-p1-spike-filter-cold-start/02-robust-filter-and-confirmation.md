# 稳健过滤能找到局部偏离，不能直接确认真假

固定倍率会受历史覆盖影响，换成局部中位数和MAD看起来更灵活：不再要求知道一个人的完整能力曲线，只比较附近的数据。但它仍然需要一个前提——附近数据的中心与离散程度适合描述当前正常行为。真实冲刺恰好可能打破这个前提。

统计异常是某个观察偏离所用参考模型；测量错误是记录没有准确反映目标量。两者不能直接等同。下面只分析四个构造窗口的中心点，不把它们当作人体数据或整段滤波准确率。

## 中位数和MAD具体做了什么

中位数是数值排序后的中间位置；MAD是所有数值到中位数的绝对距离，再取中位数。它对少数极端值不敏感，因此常用于估计局部中心和波动。

Hampel判别的一种常见形式是：

\[
m=\operatorname{median}(x),\quad
\mathrm{MAD}=\operatorname{median}(|x-m|),\quad
|x_{\mathrm{中心}}-m|>3\times1.4826\times\mathrm{MAD}.
\]

满足不等式时，方法可以把该点标记为局部异常，滤波版本会进一步用m替换。1.4826用于把MAD转换为正态参考下的尺度估计，不能让任意非平稳骑行数据自动符合正态假设。窗口和倍数会改变结果。[MathWorks官方定义](https://www.mathworks.com/help/signal/ref/hampel.html)

设七个值为200、200、200、1200、200、200、200。中位数为200，MAD为0，中心1200会被标记并替换为200。若中心真实就是1200，这次替换造成−1000的误差；若真实是200而设备错误报告1200，替换则消除了错误。输入和算法完全相同，对真实性的效果相反。[E3的两种真值](#/article/series-guide?section=publication)

## 零MAD与局部多数会改变筛查含义

把刚才中心1200改成201，其他六个值保持200，中位数和MAD仍为200和0。严格比较时，只偏离1也会超过零阈值。这不是必须除零才出现的程序问题，而是局部尺度退化后，规则的判别含义发生了变化。

如果窗口改为200、200、1200、1200、1200、1200、200，多数值为1200，中位数便是1200，MAD仍为0。中心1200不再异常。它可能是持续高输出，也可能是持续错误；局部多数本身不能决定真值。

|构造窗口的特点|中心值|中位数|MAD|是否标记中心|
|---|---:|---:|---:|---|
|六个200围绕一个1200|1200|200|0|是|
|七点中四个1200|1200|1200|0|否|
|六个200围绕一个201|201|200|0|是|
|180、190、200、240、210、220、230|240|210|20|否|

最后一行阈值约88.956，中心只偏离30，因此未标记。这些差异解释了方法依赖什么，没有给出最优窗口或新的尺度下限。本轮也没有把某个分支实现写入产品。[E3计算与解析参照](#/article/series-guide?section=publication)

平滑的爬升—衰减曲线可以提供统计线索，但不保证真实；单个尖峰也不能仅凭持续时间确定故障类型。要评价形态的实际价值，需要在带可靠标签的数据上看它增加了多少辨别信息。

## 过滤结果还可能反过来限制未来历史

设初始历史5秒最大值为400W，阈值为其1.5倍，即600W。随后三次观察依次为800、900、1000W。若只允许没有被标记的观察更新历史，三次都会被拒绝，历史始终停在400W，阈值也始终为600W。

若允许所有观察更新历史，先用旧历史判断，再纳入当前值，那么800W第一次被标记后，历史升为800W；后两次就不会超过新阈值。这只是两种数值政策的对照，不表示全部接纳正确。若第一次800W是错误，它也会污染后续参考。[E4完整事件顺序](#/article/series-guide?section=publication)

这说明清洗与历史更新可能互相影响。只看过滤后留下的记录，可能看不到真实高值被排除的过程。保留原始证据有助于重新审查，但保留不等于接受为能力真值；具体存储或审核机制需要另行设计和批准。

## 重复出现仍不等于独立确认

连续三次都记录1000W，有两种构造解释：真实值都为1000W，测量误差为0；或者真实值都为500W，同一个测量系统每次都多报500W。两种世界的记录完全相同，因此单凭重复次数无法区分它们。

后续观察是否增加证据，取决于它是否打破原来的不确定性。使用同一设备、同一计算链和同一种偏差机制，可能只是重复原来的信息。独立参照、不同测量链或可核查的设备故障证据可能帮助辨别，但它们也有校准、同步和适用范围要求。

用户或教练的情境说明也有价值，例如当时是否主动发力；它能帮助判断事件背景，不能单独确认精确瓦数。原答提出的强制冲刺复测和固定等待期没有在本轮获得验证，也不在本批实施范围。

## 方法来自其他任务，不能替代本题验证

原答用于支持冷启动的PRISM论文研究认知分数的个体化预测。实际找到的Sheridan博士论文研究团队运动中GNSS/IMU对RPE和耗氧量的预测，题名与原答所写不同。它们可以启发研究方法，已读材料并不提供自行车功率阈值或尖峰分类结果。[PRISM](https://arxiv.org/abs/2608.03877)、[DCU学位论文](https://doras.dcu.ie/31268/)

Stival等的双在线变化检测研究处理跑步活动之间的分布变化，并在活动尚未结束时估计变化概率。变化检测告诉我们当前行为与过去不同，仍需要其他证据解释是状态变化、环境变化还是设备问题。检测到变化不等于自动确定原因。[正式版摘要](https://discovery.ucl.ac.uk/id/eprint/10178753/)、[实际读取的2022预印本](https://arxiv.org/pdf/2206.11578)

Q501目前能得到的可靠结论是：固定倍率、MAD、多模态一致和重复出现都可以提出待检验的线索，不能单独完成真假判定。真实过滤方案还需要同口径的输入、可信参照、代表性错误与真实高值，以及针对下游用途的验证。本批完成这些条件的解释，没有采用新的删除规则或宣布个人能力提高。
