# 还有很多问题没解决，是否就不能交付

未解问题的总数不能单独决定是否可以交付。一个问题可能与当前用途无关，另一个问题却可能动摇全部输出。Q499要避免的，是用一个庞大清单代替对当前承诺的具体判断；同样需要避免把必要缺口改名为“远期研究”，然后当作已经解决。

“完美主义”也不是仅凭进度就能确定的心理解释。有时继续研究是在处理真实缺口，有时是在重复不影响当前决定的工作。区分两者，需要看研究结果是否可能改变拟交付的用途、对象或行为。

## 1. 先把要交付的主张写清

“能保存并重现这次计算”“能准确解释造成变化的原因”“建议能改善下一次选择”“能提高长期表现”，是不同主张。它们需要的证据范围不同，验证时间也不同。

例如，一份记录可以很快检查是否保存了输入和公式。它不能仅凭保存正确，就证明因果解释正确。一次建议可能在两天后知道有没有被执行，但两天内没有发现问题，不能证明所有后果都已观察到。把复杂承诺拆开有助于研究和交付，但不能让同一承诺通过改名获得更低的证据要求。

因此，原答提出“下一次关键课调整”作为首个产品，可以保留为候选方向；它不是由方法论推出的唯一MVP。是否选择它，还取决于用户需要、能够取得的证据、实际风险和可行替代。原答中的“即时”“48—72小时”“80%”也需要逐个回查，不能因为它们让计划显得可执行就采用。

## 2. 一个必要条件的反例

用一个人造清单看清计数关系。清单共有400项，其中a、b、c、d可能与两个假想用途有关，另外396项与这两个用途无关且全部未知。较窄用途需要a、b、d；较宽用途还需要c。这里的字母只是抽象条件，不是本产品的具体发布要求。

先令a、b、d满足，c未知，再比较d也未知的状态：

| 状态 | 用途范围 | 全清单未知数 | 当前范围依赖的未知项 |
|---|---|---:|---|
| d满足 | 较窄：a、b、d | 397 | 无 |
| d满足 | 较宽：a、b、c、d | 397 | c |
| d未知 | 较窄：a、b、d | 398 | d |
| d未知 | 较宽：a、b、c、d | 398 | c、d |

第一、二行的全局未知数相同，当前范围的缺口却不同。第一、三行的用途范围相同，仅一个共同前提的状态改变，就使这个范围出现缺口。全局数量本身既不能判定阻塞，也不能判定可以忽略。

这可以写成简单的集合关系。设U是尚未满足的条件，D(S)是用途S实际依赖的条件，则当前需要面对的缺口为U∩D(S)。缩小S可能减少D(S)，但仍位于交集中的条件不会因为范围变小而自动满足。

更重要的是，交集为空也不是发布许可。依赖表可能漏项，条件满足的证据可能不充分，实际实现可能偏离声明。本例只检查人造必要条件，不假装包含所有充分条件。因此结果文件四行都保留“未评价发布许可”。

这个构造也不是原900题的重新统计。我们没有证实其中400题大多属于长期议题，也没有确认80%都可后置。真正的范围审查需要逐项判断，与当前用途的联系不能仅从题目标题推断。

## 3. 渐进研究能够取得不同证据

静默记录、人工审核试点和与基线比较，可以分别回答不同问题。静默运行可能检查输入、计算和预测，但若某个建议从未执行，就没有观察到执行该建议的真实结果。人工审核能够增加检查机会，但[上一篇的反例](#/article/p1-011-01-human-decisions)说明，人接手后是否改善结果仍需验证。对照研究能够提供比较信息，其意义又取决于分配、结局、缺失和适用范围。

这些阶段不能互相替代，也不意味着每个产品都必须按一个固定三步方案运行。NIST AI RMF讨论根据用途、风险和影响安排工作，而不是把全部问题视为同权；它没有为此产品确定唯一首发功能。[NIST AI RMF 1.0，§1.2.3及MAP/MANAGE](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf)

同样，选择“失败课比例”作为指标，需要解释它代表什么。降低难度可能使完成率升高，却不自动实现用户想要的训练目标。这个可能性足以说明，不能把任何容易测到的改善直接命名为核心价值；是否形成实际收益，仍需与所声明的用途相匹配。

## 4. 区分等待证据与无限等待

对一个尚未解决的问题，可以按顺序说明：

1. **它影响哪一项当前承诺。** 若无法说明联系，继续研究的优先级可以重新考虑。
2. **哪些可能结果会改变当前决定。** 若不论结果如何都不改变任何选择，要检查研究是否只是重复确认。
3. **可以怎样取得这些证据。** 若目前不能取得，可以限制声明、改变用途或明确暂缓，不能将未知记成通过。
4. **范围改变后哪些依赖仍在。** 被删去的是某项真实承诺，还是只是它的措辞。

这套追问允许一部分研究与一部分交付并行，也允许合理地暂缓不具备条件的用途。它不要求先回答全部900题，但也不保证当前某项产品已经达到交付条件。

当前这批工作的交付对象是两篇方法文章和可复算构造。它们说明怎样识别证据边界，没有创建产品MVP、改变发布标准或批准真实训练建议。完整Q498、Q499仍为PARTIAL。来源与逐项判断见[证据记录](#/article/series-guide?section=publication)，分析假设见[事前方案](#/article/series-guide?section=publication)，结果与复跑入口见[研究说明](#/article/series-guide?section=publication)。
