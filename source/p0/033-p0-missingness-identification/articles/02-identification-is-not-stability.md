# 能算出唯一答案，为什么仍可能没有把握

上一例里，缺失组比例由q=(m−a)/(b−a)得到。其中a和b描述指标区分Y=0与Y=1的能力，m是缺失组可见的Z=1比例。只要b不等于a，代数上就有唯一解。但唯一性只回答“已知这些精确输入时有没有多个答案”，没有回答“输入稍有变化时答案会不会大变”。

## 区分能力越弱，同样误差影响越大

先保留真实缺失比例q=0.8。如果a=0.2、b=0.8，m就等于0.68。m增加0.01，反解q约增加0.0167，约1.67个百分点。

现在换一个很弱的代理：a=0.49、b=0.51。两个目标状态只让指标概率相差2个百分点。真实q仍为0.8，此时m=0.506。把m降低0.01得到0.496，反解q=0.3；把m提高0.01得到0.516，反解q=1.3。

两种代理都能在精确总体概率下唯一反解。然而后一种代理把一个百分点的m变化放大成五十个百分点的q变化。放大倍数就是1/(b−a)：前者约1.67，后者为50。见[D02完整扰动表](../execution/stability.csv)。

这里的±0.01是事前设定的确定性扰动，不是数据算出的置信区间。真实研究还要考虑a和b的估计误差，不能把这个简单敏感性例子冒充完整不确定性评估。

如果a=b=0.5，问题更直接：无论q是多少，m都是0.5。这时额外指标没有提供区分目标状态的信息，公式分母为零不是程序小故障，而是问题本身不能由这条关系识别。更复杂结局需要更强的条件，不能因为二元例子能解，就推断一个二元传感器标记足以恢复任意连续分布。[来源：Miao等预印本，§3 Examples 1–3](https://arxiv.org/pdf/1509.02556)。

## 1.3不该悄悄改成1

比例1.3不是一个可能的总体比例。若程序把它直接截为1，界面或许显得正常了，但它隐藏了输入与假定关系之间的冲突。

在这个精确模型里，q处于0到1时，m只能处于a到b之间。因此弱代理的m=0.516超过b=0.51，无法由任何合法q产生。实际样本频率则可能因抽样波动暂时超出范围，也可能因为假设不成立而超出；仅凭一次越界不能确定是哪一种原因。正确解释需要保留未截断结果，再回到数据精度与模型条件。

## 再强的代理，也不能靠可见数据替自己证明

稳定性还不是全部。回到较强的a=0.2、b=0.8，构造两个世界：

| 条件 | 世界A | 世界B |
|---|---:|---:|
| Y有记录的比例 | 0.5 | 0.5 |
| 记录组Y=1比例 | 0.2 | 0.2 |
| 记录组a、b | 0.2、0.8 | 0.2、0.8 |
| 缺失组Y=1比例 | 0.8 | 0.5 |
| 缺失组a、b | 0.2、0.8 | 0.5、0.86 |
| 可见的缺失组Z=1比例 | 0.68 | 0.68 |
| 真正总体Y=1比例 | 0.5 | 0.35 |

世界A满足两个R组共享代理关系。世界B不满足，但它仍能给出同一个缺失组Z比例：0.5×0.5+0.86×0.5=0.68。记录组的全部联合单元也完全相同。系统看到的数据因此无法区分这两个世界，详见[D03双世界表](../execution/worlds.csv)。

若强行沿用记录组的20%和80%，两边都会算出缺失比例80%。在世界A中正确，在世界B中错误。这个反例证明的不是“代理永远没用”，而是“代理条件不能仅因可见记录拟合得好就视为已经证实”。

论文允许部分假设在特定情况下被观察资料反驳。可反驳意味着某些数据会揭示矛盾，并不意味着每次未发现矛盾都证明假设成立。这与模型拟合或预测准确率的作用边界一致。

## “双重稳健”也有不能跳过的前提

把两个模型一起用，不会自动消除上述识别问题。Miao与Tchetgen Tchetgen讨论的MNAR双重稳健方法仍要求选择关联的log odds ratio模型正确，再满足两个基准模型至少一个正确。它并不是在任意代理、任意缺失机制下都能救回答案。[来源：2016年论文](https://doi.org/10.1093/biomet/asw016)。本次没有实现或复现这些估计器。

对训练系统，这些结果把一个宽泛要求变得具体：新指标不仅需要与目标相关，还需要有理由支持跨缺失组的关系、足够的区分能力和可接受的估计不确定性。当前没有这些真实证据，不能宣布已经恢复了未填写者的疲劳分布，更不能判断其动机。
