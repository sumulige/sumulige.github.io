# 成功率提高了，究竟有多少人因它受益

假设一个随机分配的比较给出了非常精确的结果：不用某项处理，成功率是40%；使用它，成功率是60%。一个已经接受处理并成功的人问：“我的成功，有多大可能是它带来的？”平均提高20个百分点，还不足以给出这个人的答案。

先把问题缩小到一个清楚的数学对象。用Y0表示不处理时是否成功，Y1表示处理时是否成功，1是成功。假定处理随机分配，独立于这两个潜在结局及基线分组；实际结局与实际接受的处理一致，没有相互干扰，讨论的是同一总体。下文数字都是自建演示，不是任何真实训练效果。

每个人在逻辑上属于四种类型：两种情况下都失败；只有处理才成功；只有不处理才成功；两种情况下都成功。我们看不到同一个人的两个结局，但可以限制四种类型在总体中所占的比例。

记“只有处理才成功”的比例为b，反向类型为h。两种情况下的成功率之差必然是b−h。因此，平均提高0.2可以来自20%受益、无人受损，也可以来自60%受益、40%受损。这两种解释具有相同的平均效果。

这个范围可以直接推出来。若p0、p1是两个成功率，四种类型的概率依次为1−p0−b、b、b−(p1−p0)、p1−b。要求它们全部非负，就得到：

> max(0,p1−p0) ≤ b ≤ min(p1,1−p0)。

对于p0=.4、p1=.6，受益比例是.2到.6。下面两张四格表达到两个端点。

| 类型(Y0,Y1) | b=.2的世界 | b=.6的世界 |
|---|---:|---:|
| (0,0) | .4 | 0 |
| (0,1) | .2 | .6 |
| (1,0) | 0 | .4 |
| (1,1) | .4 | 0 |

两列都满足同样的p0和p1。把这两个总体按任意比例混合，还能得到中间每个b，因此不是随意给出的一对保守数字，而是在这些条件下无法进一步收紧的界。全部端点见[四格结果](../execution/couplings.csv)。

对于随机分配后实际处理且成功的人，必要归因概率PN=P(Y0=0 | 已处理且成功)。在上述联合独立条件下，PN=b/p1，所以本例只能限定在1/3到1之间。这个条件概率以“处理成功者”为参照集合；它没有揭开某个具体人的另一个结局。[Tian与Pearl的原文](https://ftp.cs.ucla.edu/pub/stat_ser/r271-A.pdf)用PNS表达总体因果类型比例，在§4.3.1式35说明强外生性下它与PN的关系。仅知道两个因果边际时，不能省去这个条件。

这里的宽度不是样本量不足造成的。演示已经把两个总体成功率当作精确已知，即使观测无限增加，也没有自动得到同一个人的反事实配对。真实有限样本还会在这些识别限制之外增加估计误差；那需要另行构建统计推断，不能给这个范围贴上“95%置信区间”的标签。

因此，“平均效果确定”与“个人归因确定”需要不同的证据。这个例子仍然留下了可用信息：它排除低于20%或高于60%的总体受益比例。在[下一篇](02-strata-and-assumptions.md)中，干预前分层信息会进一步缩小这个集合，而不会假装我们观测到了个人的两个世界。
