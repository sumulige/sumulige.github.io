# 爬坡功率对不上，能否据此自动校准

同一段爬坡，按照体重、爬升和时间估算出的功率，与功率计记录相差十几瓦。这个差异可以提示进一步检查，但它本身没有告诉你：错的是仪器、路线参数，还是参考模型漏掉了某种阻力。

原题Q504引用的Woods等2018年论文，实际研究强化训练与静息代谢率、身体组成和表现。其公路测试方法比较四次爬坡的预测与实测功率，用来检查漂移。论文并不是一项验证自动校准算法准确率、误报率及校准后效果的研究。其39号参考文献还是Martin等2007年的会议研究，不能替换为另一篇更熟悉的1998年公路功率模型。[原论文及方法](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0191644)

这项核对改变了证据用途：作者使用过某种检查，不等于该检查已经获得你想要的性能验证。尤其不能从“研究过程中检查未见漂移”，推出“软件可以根据一次差异自动改写历史功率”。

先用最简物理关系看参考值有多依赖输入。忽略空气、滚动、传动等损耗，只计算增加重力势能所需的平均功率：

\[
P_{gravity}=\frac{mgh}{t}.
\]

构造总质量80kg、净上升1000m、用时2400秒、重力加速度9.81m/s²，得到327W。这里的质量包括骑手与装备，h是净高度变化；这只是理想重力项，不能冒充完整的曲柄功率。

| 仅改变一个假设 | 参考功率相对327W的变化 |
|---|---:|
| 净高度多10m | +3.27W |
| 总质量多1kg | +4.09W |
| 用时少10秒 | +1.37W |
| 另外计入构造的15W阻力项 | +15W |

这几项不是误差分布，也没有说明真实路线通常会错多少。它们只是敏感性演示：参考模型自己也会移动。若用一个遗漏15W阻力的参考，去校准一块恰好正确的功率计，校准操作反而可能引入偏差。[D03计算](../execution/results.json)

还需要避免把位置不同的功率当成同一个真值。重力功对应整车势能变化，曲柄测量对应传动前的输入；未建模的阻力、动能变化和传动损失都会进入二者差额。即便连续几次差额稳定，也只能说明这个组合在那些条件下稳定，不能单独识别哪一项造成了偏差。

因此，Q504在本批得到的答案是：爬坡参照能够作为异常线索，但从线索到自动校准还缺归因和效果验证。要支持后一步，需要独立可信的参照、明确的功率位置和误差来源，以及修正后在独立测试中的表现。这些是缺失证据的类型，并非已经批准的实施流程或新的验收阈值。

证据状态：引用身份及其检查用途为VERIFIED；理想公式和敏感性计算为VERIFIED；真实路线校准性能、误报率和用户收益为UNKNOWN。本批没有更改设备设置、原始活动或历史功率。[研究决定](../stages/06-decision.md)
