# 两项结果各有一半概率变好，还缺什么信息

假设X与Y分别表示两个目标是否实现，1表示实现、0表示未实现。系统都预测为一半概率实现。这样的两条预测，足够比较方案吗？如果你重视两者同时实现，答案还取决于它们如何共同发生。

先比较两个极端。第一个世界中，要么两个目标一起实现，要么一起未实现，各占一半。第二个世界中，两个目标轮流实现，始终恰好实现一个。两世界里，单独看X或Y，实现概率都为一半。但同时实现的概率分别是1/2与0。

这种差别是否影响选择，取决于已明确的效用结构。若效用是`u_add=(X+Y)/2`，两个世界的期望值都为0.5。更一般地，`E[f(X)+g(Y)]=E[f(X)]+E[g(Y)]`，这里不要求X与Y在统计上独立。

现在在[0,1]×[0,1]的达成程度上定义另一种效用`u_int=0.3X+0.3Y+0.4XY`，表示除各目标本身外，同时达到高水平还有额外价值。随机方案的结果只落在0或1，后面用于比较的确定方案则允许落在中间水平。令共同实现概率为t，为保持两条边缘概率都为1/2，四种结果的概率必须是：

| 结果 | 概率 |
|---|---|
| (0,0) | t |
| (1,0) | 0.5−t |
| (0,1) | 0.5−t |
| (1,1) | t |

其中0≤t≤0.5。交互效用的期望为`0.3+0.4t`，会从0.3变化到0.5。若与一个确定达到(0.5,0.5)的方案比较，这里0.5表示实际达成一半水平，不是成功概率，后者效用为0.4；t小于0.25时选确定方案，大于0.25时选这项随机方案。单独两条“一半概率”的预测无法决定这个排名。[联合概率与汇总](../execution/joint-summary.csv)

把两条均值0.5直接代入效用，会得到0.4，恰好等于假设两目标统计独立时的结果。这样做隐含选了t=0.25；它没有凭两条边缘预测证明独立。对这个特定效用，所缺的信息其实只需要共同实现概率t；并非所有决策都必须建立一张完整高维联合分布。

这里还要区分两种“独立”。统计独立描述结果如何共同出现；加性独立描述决策者是否对边缘相同、联合方式不同的抽奖无差别。Bacchus与Grove的定义2.7明确讨论后一种含义。数据相关本身既不能证明效用必须含交互，也不能证明加性效用无效。[原方法](https://arxiv.org/pdf/1302.4928)

本例四角效用为0、0.3、0.3、1，交叉差`1−0.3−0.3+0=0.4`。任何精确的单变量加和在这个差上都应为0，因此这些已指定的基数数值不能原样写成两个单变量函数之和。这个论证没有排除某些单调变换下的确定结果排序表示，也不要求所有用户都认可这套数值。

回到Q002和Q341，不能先从“这些指标相关”跳到“不能相加”，也不能从“已归一化”跳到“可以相加”。需要分别说明价值结构与结果概率。Q010中若目标确实强调多个能力同时具备，还需要与该目标对应的联合信息；这项需要不能由多列平均分自动满足。
