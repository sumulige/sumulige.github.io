# 平均收益更高，为什么还不能直接叫“更合意”

方案S确定得到4个结果单位；方案R有一半机会得到0、一半机会得到10。R的平均结果为5，高于S的4。但是否更合意，还取决于如何评价这些不确定结果。

如果明确采用线性效用`u(x)=x`，比较期望效用就会选R：5大于4。这是一个清楚的决策定义。

换成另一种明确的偏好`u(x)=sqrt(x)`，S的效用为2，R的期望效用却是`(sqrt(0)+sqrt(10))/2≈1.5811`，于是选择S。我们没有发现R的预测错了；改变的是评价这些结果的偏好。

两种效用都认为确定的10好于确定的4、4好于0。仅知道用户对确定结果的排序，仍不足以确定用户在这两个不确定方案之间的选择。多属性效用方法把对不确定性的态度纳入效用，而不只记录确定结果的排序。[Bacchus与Grove，§2](https://arxiv.org/pdf/1302.4928)

一个常见计算错误是，先求平均结果5，再取平方根，得到约2.2361，与S的2比较。这算的是`u(E[X])`，不是`E[u(X)]`。前者把有波动的方案替换成了确定得到均值的方案；在非线性效用下，这个替换通常改变问题。

在平方根偏好下，与R具有相同期望效用的确定结果是多少？解`sqrt(CE)=1.5811`，得到确定等价CE=2.5。它与R的均值5不同，也没有改变R实际可能得到0或10的事实。[结果表](../execution/lotteries.csv)

这还解释了为什么“只是换个分数表示法”需要谨慎。将平方根效用变为`2sqrt(x)+7`，是同一效用的正仿射变换；所有方案的期望效用都按相同比例平移缩放，因此仍选S，确定等价仍为2.5。直接将平方根改回x，虽然保持确定结果排序，却会改变不确定方案排序。它不只是无关紧要的显示调整。

本文没有主张平方根比线性正确，也没有为用户指定风险偏好。2024年MCDA指南将风险态度评估与结果不确定性分析分别说明；具体偏好需要来自相应决策者，而不是从预测方差自动导出。[官方指南“Attitude to risk”](https://analysisfunction.civilservice.gov.uk/policy-store/an-introductory-guide-to-mcda/)

对Q010而言，“更强”的结果定义和“怎样评价不确定的变强机会”是两个需要衔接的问题。对Q341而言，预测某种不利结果的概率降低，也不等于用户对该结果的厌恶程度降低；预测模型更新和偏好权重变化不能自动视为同一件事。真实训练风险与代价没有在本例中量化。
