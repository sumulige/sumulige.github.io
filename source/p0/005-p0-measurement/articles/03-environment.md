# 环境变了，哪些影响应该校正

同样的训练，在高温、逆风或不同器材下，速度、功率和心率可能呈现不同关系。Q019和Q153希望从表现里分离环境影响，Q504进一步追问：用心率去更新室内功率因子，会不会越校越偏？

回答前要先明确要比较什么。若目标是估计常态条件下的能力，环境差异可能妨碍跨次比较；若目标是理解热环境中的实际负担或目标赛事表现，环境作用就是问题的一部分。把它全部扣掉，会丢失需要解释的信息。

## 1. 环境作用不等于测量误差

功率计因温度而读错，与人在热环境中产生不同的生理反应，是两种机制。前者属于仪器测量问题，后者可能是被真实记录的身体变化。热环境中的心率升高，不应未经判断就称为虚高。

Wingo与Cureton的受控骑行研究比较了不同风扇降温条件。摘要报告，风扇条件下心率上升和最大摄氧量下降均较小。这支持散热条件可以改变实际生理负担；本轮仅核对摘要，没有据此推导任何人的安全阈值或室内功率折扣。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/16896737/)

逆风对速度的影响又属于机械关系。在相同测点且测量准确的前提下，功率可以帮助区分做功与速度，但功率本身也不告诉我们这次是否最大努力、疲劳多少或热负担多大。速度若是计时赛等任务的结果，仍有意义。应把这些量放回具体任务，而不是一律删去某个指标。[道路功率模型](https://doi.org/10.1123/jab.14.3.276)

## 2. 因子会往哪边偏，取决于定义

用一个纯演示模型说明：

\[
H=60+0.4P+10E,
\]

H表示心率，P表示真实功率，E表示某项环境条件是否出现。这里的系数全部是构造值。P=200、E=0时，H=140；同样输出而E=1时，H=150。

如果算法忽略E，仍用H=60+0.4P反推，它会把150解释成225瓦。定义因子为反推的常态功率除以实测功率，得到225/200=1.125；若定义为它的倒数，则得到200/225≈0.889。两者都来自同一组记录，数值方向却相反。[案例M05](../execution/results.json)

因此，旧答中因子必然过小的说法，缺少更新公式便不成立。能够确认的风险是：算法可能把环境对心率的作用归入功率映射。偏差的符号、幅度以及它怎样影响后续课表，都需要沿实际公式追踪。

即使把E加入模型，也需要足够数据估计它。这个例子没有证明225瓦是实际等效训练剂量，更没有证明固定的10次/分钟环境修正有效。固定截取第5–15分钟或用5%解耦作门槛，同样需要针对用途验证。

## 3. 训练营里，时间与环境可能分不开

设一个简化模型：

\[
y=\alpha+\beta T+\gamma E.
\]

T表示训练营前后，E表示常态或特殊环境。假如营前只在常态测量，营后只在特殊环境测量，那么数据中始终有T=E。营前测得250，营后测得230，只能确定β+γ=−20。

以下三种解释都会给出完全相同的记录：

| 时间相关变化β | 环境效应γ | 合计变化 |
|---|---|---|
| 0 | −20 | −20 |
| +10 | −30 | −20 |
| −20 | 0 | −20 |

此时无论再记录多少个同样结构的日子，缺少的比较条件仍然缺少。计算中包含截距的设计矩阵只有两个独立方向，无法分别估计三个参数。正则化或先验可以选出一组解，但选择会依赖附加假设，不能说数据已经自行拆开了原因。

在这个理想化模型中，如果能在T=1、E=0的条件下取得可比观测，例如260，三组解释的预测分别为250、260、230，才出现区分信息。[案例M07](../execution/results.json)

真实训练营更复杂。返回常态时，恢复、适应和时间可能又改变了；环境作用也可能与适应状态相互作用。一个回程测试不会自动识别全部机制。所需比较、测量条件和模型假设应在具体研究中确定，本轮没有安排真人试验。

## 4. 当前能保留的结论

对Q019，应先说明要估计常态能力、条件下表现还是实际负担，再确定哪些影响需要建模。对Q153，应检查环境与时间是否有可比较的重叠，缺少时报告不同解释的范围。对Q504，应先把因子定义、输入和更新式写完整，再验证其误差如何传播。

这三个限定方法结论为VERIFIED，原题整体仍为PARTIAL。真实个体环境效应、短期校正是否稳定，以及是否能改善训练决定均为UNKNOWN。本轮不支持统一冻结CTL、固定下调功率比例或固定返程恢复天数，也没有把双曲线等架构提案转成已实施功能。
