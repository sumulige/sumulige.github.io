# 把初值设为零，究竟设定了什么

“从零开始”可以指三件不同的事：优化程序的搜索起点为0；状态的先验均值为0，但允许很大不确定性；或者认定初始状态恰好等于0。这三种做法对后续数据的作用完全不同。

搜索起点通常只是数值算法的设置，理论上不应改变要计算的概率模型；它仍可能影响局部优化能否找到好解。先验均值则是概率假设的一部分。若连先验方差也设为0，就不是“暂时不知道，所以先填零”，而是把所有概率都放在零上。

继续使用[前篇的衰减模型](01-history-and-initial-information.md)：x_t=0.9^t x0，观测误差方差1，没有过程噪声。构造五个观测值10、9、8.1、7.29、6.561。它们是按初值10生成的无扰动轨迹，不是随机样本或实际表现记录。比较先验均值均为0，但方差不同的推断：

| 初值先验方差 | 初值后验均值 | 初值后验方差 |
|---:|---:|---:|
| 0，点质量 | 0 | 0 |
| 0.01 | 0.33144 | 0.009669 |
| 1 | 7.74165 | 0.225835 |
| 100 | 9.97091 | 0.290866 |
| 平坦先验极限 | 10 | 0.291715 |

计算使用同一似然与同一五点观测，全部设置见[先验结果表](../execution/priors.csv)。正有限先验方差P0下，后验精度是1/P0+I，其中I是观测对初值的信息。初值先验越强地集中于0，数据把估计拉向10就越困难。

点质量的情况更直接：原先只有x0=0具有概率，正常更新不会凭空把先验为零的其他取值变成可取的初值。即使数据与零轨迹相差很大，正态观测噪声仍允许这些观测，模型也可以把差异留给噪声。此时输出的零方差是设定的确定性，不是数据验证了初值正确。

这一结论依赖本例边界。若模型允许过程噪声，后续状态可因创新项改变并从新测量中学习；但这不等于原先固定为零的x0本身已被重新估计。若程序另外修改了初值分布，则是在改变假设，不能称为同一个固定初值模型自然学会了。

Zhao与Huang讨论Kalman初始化时，也明确区分了初始均值和协方差的作用。本轮实际读取其出版方摘要、引言及模型开头，没有实施其变分初始化算法。[初始化方法论文](https://www.sciencedirect.com/science/article/abs/pii/S0005109820303824)

表中最后一行也需克制解释。它是本例高斯线性问题里可直接计算的平坦先验极限；有足够非零观测系数后，后验仍是适定的。它不等于对任意模型填入一个极大数字，更不证明已经实现了文献中的exact diffuse初始化。多维未观测方向、数值稳定性、参数未知和实际先验知识，都可能改变处理方式。

所以，Q319提出用平滑估计初值，至少要先说明初值在模型里是否真的可估计。Q023与Q478中“状态空间会修正初值”的说法也需要条件：状态空间是表达方式，能否修正取决于初值是否保留不确定性、观测是否提供信息，以及推断是否正确完成。

本篇数学比较VERIFIED；实际初值分布选择UNKNOWN。它不主张总用宽先验，也不批准替换现有初始化策略。[来源范围](../stages/02-sources.md)｜[方案](../stages/03-protocol.md)｜[结果](../stages/04-results.md)。
