# 冷启动借用群体信息，关键在于这份信息有多适合他

Q028把“新用户前8周”作为冷启动窗口。八周能积累多少信息，取决于观测次数、相关性、噪声、训练输入变化和模型要区分的量。仅有日历长度，无法判断什么时候应该摆脱群体先验，也无法保证此时已经识别出个人参数。

## 1. 群体信息和个人数据怎样共同影响结果

先用一个可算清的模型说明。设个人目标参数θ的先验为N(m₀,s²)，个人有n次独立观测，每次误差方差为σ²，样本均值为ȳ。则样本均值的观测方差为σ²/n。正态模型的后验精度是先验精度与数据精度之和：

\[
V^{-1}=s^{-2}+n/\sigma^2.
\]

后验均值可写成：

\[
m=(1-w)m_0+w\bar y,\qquad
w=\frac{s^2}{s^2+\sigma^2/n}.
\]

精度是方差的倒数，表示这个模型内信息的集中程度。先验越宽，数据的相对权重越大；个人数据越精确，它们也获得更大权重。所谓汇聚，是两个信息来源按其假定精度共同影响结果，不能理解为先把人强行放到群体均值，再等一个固定周数才允许个性化。

设m₀=0、ȳ=3、单次观测方差σ²=4。下面都是演示数值，不是训练参数：

|先验方差s²|独立观测数n|数据权重w|后验均值|后验方差|
|---|---:|---:|---:|---:|
|1|1|0.2000|0.6000|0.8000|
|1|8|0.6667|2.0000|0.3333|
|1|32|0.8889|2.6667|0.1111|
|4|1|0.5000|1.5000|2.0000|
|4|8|0.8889|2.6667|0.4444|
|4|32|0.9697|2.9091|0.1212|

同样一个观测，窄先验让结果更接近0，宽先验则允许结果向个人数据移动得更多。较窄的后验可能意味着信息恰当，也可能意味着先验过度确信；仅凭窄不能判断哪一种。公式中s²是个人参数在所设先验中的不确定性，不是已经由本轮数据验证的群体差异。[案例I04](../execution/results.json)

## 2. 增加的是均值信息，不是让单次噪声自动消失

在上述所有行里，σ²始终为4。随n增加而下降的是ȳ的方差4/n。原答把“更多数据使个人估计更稳定”写成“测量噪声随周数下降”，会混淆这两个量。

4/n还依赖独立、相同误差方差和稳定目标参数。若连续观测共享同一天状态、同一设备偏差或长期趋势，不能简单把记录条数全部算作独立信息。若参数本身随训练变化，用很久以前的数据估计今天的参数也需要额外模型；这时收集更多记录甚至可能在精度和时效性之间产生取舍。

在冲量—响应模型里，还存在比记录条数更深的问题。若输入几乎不变，数据可能反复告诉我们同一个稳态组合，却很少帮助区分增益与衰减时间。[前一篇的山脊例子](01-joint-posterior.md)说明，增加相似观测不必然解除参数补偿。

## 3. 先验来自哪一群人，比“使用了分层模型”更重要

上面的推导假定先验已经给定。真实冷启动首先需要回答：群体样本是否与新用户在运动项目、测量协议、训练背景和结果定义上足够相关，哪些差异应进入条件化，哪些差异目前未知。

按项目、年龄或训练史划分人群可能帮助建模，但这些标签本身不证明组内可以交换信息。划得更细也会减少每组材料；继续增加分组可能得到很精致、却证据很少的先验。群体平均值估得精确，也不代表每个新个体都接近它。群体均值的不确定性、个体差异和单次测量误差是不同来源。

[Peng等作者稿](https://www.sfu.ca/~tswartz/papers/impulse.pdf)提供了用先验限制模型的具体范例；其单名跑者材料不构成一个适用于新骑行用户的群体先验库。本轮也没有估计此类库。已有模拟中围绕真值构造的先验可以检验“若先验很有利会怎样”，不能证明现实中可取得同等信息。[来源边界](../stages/02-sources.md)

## 4. 把先验依赖本身写进结论

冷启动阶段，一个有用结果可以是：“在这几种有依据的先验下，预测方向一致，但个别参数仍宽。”另一个同样有用的结果是：“改变先验后，行动排序改变，现有个人数据不足以支持稳定选择。”后者应推动补充有区分力的观测，或限制用途，而不是把区间压窄以获得看起来明确的答案。

下一步需要与目标用户和测量协议匹配的群体材料，明确其筛选与差异来源，再检查先验敏感性、独立个体上的预测和实际可取得的输入。本轮没有确定默认先验、冷启动周数、分层架构或自动训练规则。

本题状态为**PARTIAL**：正态条件下的信息汇聚关系已完成解析与数值核对。新用户应借多少群体信息、多久足以个性化及由此产生的训练收益仍为**UNKNOWN**。这份不确定性应留在输出中，让后续数据有机会真正改变判断。
