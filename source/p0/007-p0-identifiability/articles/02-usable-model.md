# 稀疏数据下，先说明模型要用来做什么

Q023希望得到“可用而非过拟合”的模型。可用需要一个明确用途：解释某个生理参数、预测未来表现，还是比较两个训练动作。这三个任务可以使用相似公式，却需要不同证据。参数很难分别识别时，某个组合的预测仍可能稳定；预测在既有数据中稳定，也不自动说明改变训练后会得到预期收益。

## 1. 参数区间、预测误差和行动收益分别核对

[前一篇](01-joint-posterior.md)给了一个最小例子：τ的标准差约17，派生稳态S的标准差却仅约0.05。参数不确定，不等于所有派生量都同样不确定。反过来，先验把参数范围压窄，也可能使输出显得稳定，而没有证明先验适合这个人。

如果用途是预测，问题变成：在训练时没有使用的未来观测上，模型是否比简单基线更好，误差在什么情形变大。如果用途是解释参数，还要检查参数恢复、先验依赖、输入信息和模型错设。如果用途是选择训练动作，则需要观察性因果识别条件或适合的干预研究。仅把预测器换成状态空间或贝叶斯形式，不会自动补齐这些证据。

[Marchal等2025年的研究](https://doi.org/10.1038/s41598-025-88153-7)在其短道速滑数据和分析条件下区分了拟合与时间留出预测，支持继续追问“拟合改善是否转为预测改善”。它不是所有训练模型的统一判决。[Peng等作者稿](https://www.sfu.ca/~tswartz/papers/impulse.pdf)展示了贝叶斯约束和相关误差的做法，也不能仅凭较窄区间证明恢复了真实生理参数。两项材料的人群、目标和版本不同，不宜当作同条件的正反实验。

## 2. 已保存模拟提供了一次有限的比较

本轮没有重新拟合模型，而是读取此前模拟的完整汇总与配对结果。每个密度条件有140个重复；训练期140天，留出28天。稠密条件有140次训练观测，稀疏条件20次。这里的目标μ是模拟生成的无噪声均值；对应真实观测y的误差另有记录。

下表先在每次重复内计算28天RMSE，再对重复取平均。模型列使用原数值通过集合，基线使用全部140次。分母不同，因此表中的跨模型均值不能视为同一批样本的直接配对排名。

|方法|稠密平均RMSE(μ)|纳入重复|稀疏平均RMSE(μ)|纳入重复|
|---|---:|---:|---:|---:|
|上一观测值|0.4499|140/140|0.4494|140/140|
|训练期观测均值|0.9775|140/140|0.9686|140/140|
|非线性最小二乘NLS|0.1021|140/140|30.8192|140/140|
|P0|0.0941|132/140|0.2139|125/140|
|P1|0.0700|140/140|0.1473|140/140|
|P2|0.0867|140/140|0.1690|138/140|

这里P0、P1、P2是原模拟中的先验方案标签，与研究题目的P0优先级无关。P0与P1的先验中心都利用了已知生成参数；P1进一步收紧范围，是有利条件下的参照。现实中不能假定提前知道真值，见[原模拟方案](../../../2026-10-22-ir-simulation-plan.md)。模拟中未来训练输入已知，模型结构也与生成条件密切相关，这些便利进一步限制了推广范围。

原贝叶斯流程数值通过815/840次。NLS的优化成功与MCMC的数值诊断不是相同的保证；不能因为两个结果都标“通过”，就认为其预测风险等价。[保存汇总](../../003-observation-and-decisions/execution/baseline-summary.csv)同时保留全部完成结果及通过子集，不能把未通过部分从整体报告中省略。

## 3. 多数重复胜出，也可能伴随严重尾部错误

稀疏NLS相对上一观测值，在88/140个重复中μ的RMSE更低。配对误差差值“模型−基线”的中位数为−0.0442，看起来略有改善；但同一差值的平均数为+30.3698，方向相反。

两种统计量没有矛盾。中位数描述排序中间的位置，均值受每次误差幅度影响。少数很大的错误足以抵消较多的小幅改善。只报告胜率会掩盖损失规模，只报告均值又不足以描述典型重复。应保留误差分布、失败分母和发生条件，再由具体用途判断哪种风险最重要。[完整配对表](../../003-observation-and-decisions/execution/paired.csv)

这也是为什么不能把优化器返回成功当作可用性的终点。优化成功描述求解过程的某个条件；留出预测差可能来自参数补偿、观测不足、目标函数与未来用途不同，或者其他模型问题。本轮只核对了保存结果，没有重新归因这些原因，更没有据此设定产品回退阈值。

## 4. 下一项研究应围绕用途展开

如果目标是短期预测，可在时间留出的条件下比较上一观测值、简单趋势和候选模型，同时保留真正可取得的未来输入、全部计划重复和数值失败。若目标是参数解释，需要另一组设计：检查不同输入模式、观测时点、先验和模型错设是否仍能恢复目标参数。若要据此改训练，还需要进一步验证行动收益。

这不是要求同时扩大所有研究。应选择一个足以改变判断的用途，明确合理基线、评价目标和失效代价，再补相应证据。原答的固定模型错误概率门槛没有在本轮得到依据，不能作为默认上线规则。

本题状态为**PARTIAL**：已用保存的完整分母和配对结果解释何为有限预测证据。真实骑行人群的预测性能、生理解释和训练决策收益均为**UNKNOWN**。五案例与输入位置见[执行记录](../execution/results.json)。[下一篇：冷启动先验](03-cold-start.md)。
