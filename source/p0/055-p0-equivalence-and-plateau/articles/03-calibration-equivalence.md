# 正好80%的覆盖，不等于已经证明校准足够好

Q423提出：后验80%区间的实际覆盖率不显著偏离80%，可作为参数恢复测试的通过条件。但“不显著偏离某个点”和“有足够证据位于一个容差带内”，需要不同检验。

例如50个独立合成样本中有40个覆盖，点估计正好为80%。这个观察当然与80%相容；它也可能与相当宽的一组真实覆盖率相容。如果要排除过低或过高的覆盖，仍然需要精度。

## 1. 先明确本次要证明的容差

本篇只用(75%,85%)作为数学演示范围，不将它批准为真实校准验收标准。令X是n个独立、同概率覆盖指标中的成功数，X服从Bin(n,p)。目标是支持0.75<p<0.85。

对下边界0.75，观察到的覆盖数必须大到其右尾概率P(X≥k)<0.05；对上边界0.85，覆盖数必须小到其左尾概率P(X≤k)<0.05。两项都满足，才支持演示容差内等效。由于成功数是整数，接受区间可能不对称，也可能根本不存在。

计算使用整数二项权重与严格尾部不等式，不依赖大样本正态近似。最终另用80位十进制递推重建全部分布。

| 独立样本数n | 支持75%–85%等效的覆盖数k | 普通80%点原假设检验不拒绝的k |
|---|---|---|
| 50 | 无 | 34–45 |
| 100 | 无 | 72–88 |
| 250 | 200–202 | 187–212 |
| 500 | 392–411 | 382–417 |
| 1000 | 773–830 | 775–824 |

普通点检验在这里定义为中央等尾5%检验，两尾各2.5%，使用精确二项概率。它的接受范围与等效范围回答不同问题：n=1000时，某些覆盖数已经与精确的80%点假设不相容，却仍能支持75%–85%的容差。这是“小而精确的偏离”与“足够接近”同时成立的二项版本。[整数接受区间](../execution/acceptance.csv)

## 2. 原来的样本量公式没有回答通过概率

在真实p恰好为80%时，得到等效通过的概率如下：n=50和100均为0；n=250为18.6416%；n=500为73.1456%；n=1000为97.6996%。相应的普通点检验不拒绝概率都约为95%或略高，因为整数分布使检验偏保守。

因此，用误差范围公式得到大约250个样本，并不意味着“真正校准的模型有80%或95%概率通过等效检验”。区间宽度设计、检验功效和观测后结论是三个相关但不同的目标。本文也没有推荐所有系统用1000个样本；目标、容差和独立单位首先要确定。

在n=50、真实覆盖率70%时，普通点检验仍有68.3707%的概率不拒绝80%。如果以“不拒绝”为校准通过，这一规则相当容易放过明显偏离本篇演示容差的情况。精确等效检验在p=75%或85%边界的误通过概率不超过5%，完整五种p、五种n见[概率表](../execution/calibration.csv)。

## 3. 这仍不是产品或训练有效性的证明

二项计算假设每个覆盖结果独立且具有共同p。同一用户每天的预测、同一共享参数下的多个结果、选择性保留的测试，不会因为记录有1000行就自动变成1000个独立试验。不同人群混合还会隐藏分组低覆盖。

即使整体容差得到支持，也只说明这项覆盖指标在定义的实验分布下符合要求；不证明区间足够窄、预测有决策价值、模拟器描述了人，或训练建议会带来收益。

这里把TOST的双边逻辑扩展到二项校准问题，属于本次自拟分析。[原方法说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC5502906/)不提供本表的产品验证结论。原题仍为PARTIAL，真实系统适用性UNKNOWN。
