# 数据太少时，“没显著进步”最容易被误读

假设你观察一段时间，没有检出显著变化。可能确实没有值得在意的变化，也可能只是估计太不精确。要将前者与后者区分，就需要检验“变化足够小”，而不是把“变化检验失败”直接当答案。

Q711原答案把斜率不显著、前后差值小和平台期放在同一段定义中。这些不是等价条件。这里用一个单次固定分析的例子展示差别；没有制定12周平台期标准，也没有把后验标准差当作已知抽样标准误。

## 1. 等效有一个最低精度要求

设n个独立观测都来自均值δ、已知标准差1的正态分布，估计均值δhat的SE为1/√n。继续使用纯演示等效范围(−0.2,0.2)。TOST在5%水平通过的条件是

|δhat| < 0.2−1.64485/√n。

右侧若小于或等于0，任何估计值都不能通过。这是因为90%区间已经比整个等效范围还宽；就算点估计恰好为0，也没有足够精度排除范围外的值。

| n | 真实变化δ | 支持等效的概率 | 普通差异检验“不显著”的概率 |
|---|---:|---:|---:|
| 20 | 0 | 0% | 95% |
| 20 | 0.3 | 0% | 73.1338% |
| 100 | 0 | 27.7520% | 95% |
| 200 | 0 | 76.3418% | 95% |
| 1000 | 0.1 | 93.5420% | 11.4621% |

第一行最直观：实际没有变化，但研究仍不能提供足够精确的等效证据；不显著却很常见。第二行更危险：真实变化0.3已经超出演示等效上界，研究仍约73%概率得到“不显著”。把“不显著”贴成平台期，会把精度不足写成状态结论。

最后一行与前篇第三种结果呼应：真实变化0.1很小，足够多数据既能常常检出它不同于0，也能常常支持它位于(−0.2,0.2)。两个事件并不互斥。[完整20种条件](../execution/power.csv)

## 2. 错误率控制与检出概率是两回事

在真实δ等于0.2的边界上，本例等效通过概率不超过5%；若真实δ再大，误判概率更小。但这不保证范围内的任何δ都很容易被判断为等效。越靠近界值，要同时排除两个方向越困难。

对一个已观察到的“通过”结果，也不能把5%解释为“本次判断有5%概率错”。这里控制的是固定真值下重复开展同一研究的错误频率。它依赖已知方差、正态独立观测、事先界值和固定分析时点等条件。

把连续每天查看的结果套入这张表，会改变停止规则；真实数据相关、缺失、设备漂移或模型偏差也会改变概率。前述数字因此不能直接用作运动员监控阈值。

## 3. 平台期还需要一个实质定义

同一个人可以阈值不变而耐久度提升，也可以因为没有合适测试而被模型估计为不变。统计等效最多回答所定义指标、尺度、时间窗和模型下的变化范围。它不能替代“哪些变化算进步”的选择，更不能证明某种训练无效。

本例沿用原文TOST的拒绝结构，概率由已知正态分布直接积分得到。[方法原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5502906/)。文章未采用原答案的SWC+TE规则，也没有把资源允许测出的最小变化当作用户应该在意的最小变化。
