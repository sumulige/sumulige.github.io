# 如果第一题可能没有回答，原来的最佳顺序还成立吗

上一例的优势依赖一个关键条件：背景问题C能得到回答。如果它没有回答，而且这一分支要求停止，就不能再沿用“先C、后对应状态”必然成功的计算。

保持相同的八个世界、同样的每题成本0.1。现在背景问题以概率r得到回答，且这件事与真实状态独立。若回答，继续问对应状态；若未回答，停止。状态问题本身保证回答。这里只比较三个事先声明的策略，不穷尽所有可能策略。

立即停止的错误率是0.5，总损失0.5。直接问X0一次再停止，错误率0.25，总损失0.35。这两者不依赖r。

先问背景问题的策略则不同。概率r的分支能准确得到目标，概率1−r的分支只能保留最初判断，错误率0.5。因此平均错误率是`0.5(1−r)`。第一题无论是否有回答都已付出成本，第二题只在回答后询问，平均问数是`1+r`。总损失为：

`0.5(1−r) + 0.1(1+r) = 0.6−0.4r`。

| 背景题回答概率r | 先背景题的总损失 | 直接问X0的总损失 |
|---|---|---|
| 0 | 0.60 | 0.35 |
| 0.25 | 0.50 | 0.35 |
| 0.50 | 0.40 | 0.35 |
| 0.625 | 0.35 | 0.35 |
| 0.75 | 0.30 | 0.35 |
| 1 | 0.20 | 0.35 |

只有r>0.625时，这个背景题策略才严格优于直接问X0。这个数是当前构造的交点，不是任何产品的问卷完成率门槛；换成本、回答误差或允许的分支，交点都会变。[全部结果](../execution/nonresponse.csv)

这里将未回答后的停止写进了允许的策略。计算收益时必须尊重这个限制，不能先计算“继续追问会更好”，再把它当成继续询问的授权。拒绝、退出和一次无回应也不应被自动当作同一事件；真实系统须先明确具体情形和用户选择，本例没有替产品作出这项决定。

我们还特意让回答与状态独立，因此“未回答”本身没有提供疲劳或能力信息。如果现实中缺失与状态有关，需要另有证据建立回答机制；单看完成率无法确定这个关系。Q130与Q790中关于记录和追问的主张，都不能由这张表直接获得生理解释。

三篇文章合起来限定了一个研究判断：组合与顺序值得评估，但候选策略只能在已允许的动作内比较，而且要把无回应分支计入。此前[单次提问研究](../../006-p0-missingness/README.md)讨论的信息价值和负担，在多步情况下仍然存在；本轮新增的是它们如何随历史和后续选择改变。
